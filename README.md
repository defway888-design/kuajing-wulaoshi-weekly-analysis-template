# 跨境吴老师周数据分析Skill用户操作说明

## 一、这个 Skill 可以做什么

跨境吴老师周数据分析Skill用于每周自动分析父商品数据：

```text
获取业务数据
→ 分析父商品流量和转化率单周期异动
→ 对接近阈值的父商品补充判断30天趋势异动
→ 对高优先级异动ASIN生成诊断报告
→ 生成负责人汇总表和异动明细表
→ 生成BI看板
→ 按权限向老板和负责人发送邮件
```

老板可以看到全部汇总数据。每个负责人只能收到自己负责商品的异动明细。

如果出现高优先级异动，系统会按异动类型生成对应ASIN的 Word 诊断报告：

```text
流量异动：调用流量异动诊断
转化率异动：调用转化率异动诊断
流量+转化率异动：同时调用两类诊断并合并为一份报告
```

### 运行前提

使用本 Skill 前，需要先开通并配置好领星 MCP。

```text
领星 MCP 已开通
→ 已完成领星 MCP 授权配置
→ Codex 可以正常调用业务数据
→ 才能运行跨境吴老师周数据分析Skill
```

如果尚未开通或配置领星 MCP，请先完成数据调用配置。Skill 本身不提供领星账号开通服务。

## 二、首次安装

### 1. 登录 GitHub 并提交用户名

Skill 保存在私有仓库中：

```text
https://github.com/defway888-design/kuajing-wulaoshi-weekly-analysis-template
```

首次安装前，需要先将自己的 GitHub 用户名提交给跨境吴老师。

操作步骤：

```text
登录 GitHub
→ 点击右上角头像
→ 选择 Your profile
→ 进入个人主页
→ 复制浏览器地址栏中的完整网址
→ 将网址发送给跨境吴老师
```

示例：

```text
https://github.com/zhangsan-2026
```

其中：

```text
zhangsan-2026
```

就是需要提交的 GitHub 用户名。

注意：

```text
GitHub 用户名不是邮箱。
请不要发送邮箱密码、GitHub密码或其他授权信息。
```

### 2. 接受私有仓库邀请

跨境吴老师收到 GitHub 用户名后，会发送私有仓库访问邀请。

用户操作：

```text
登录 GitHub
→ 打开 GitHub 发送的邀请邮件
→ 点击 View invitation
→ 点击 Accept invitation
```

接受成功后，打开以下仓库地址：

```text
https://github.com/defway888-design/kuajing-wulaoshi-weekly-analysis-template
```

如果可以看到仓库页面和文件列表，说明已经获得访问权限。

### 3. 在 Codex 中发出安装指令

打开 Codex，新建一个对话，输入：

```text
请从以下 GitHub 私有仓库安装跨境吴老师周数据分析Skill：
https://github.com/defway888-design/kuajing-wulaoshi-weekly-analysis-template
```

按照 Codex 提示完成 GitHub 授权。

### 4. 重启 Codex

安装完成后，关闭并重新打开 Codex，使 Skill 生效。

## 三、第一次执行

重新打开 Codex 后，输入：

```text
使用跨境吴老师周数据分析Skill，执行本周异动数据分析。
```

首次运行默认进入：

```text
试运行模式
```

试运行模式只生成分析结果，不会自动发送正式邮件，也不会自动创建每周任务。

执行过程中会看到类似提示：

```text
跨境吴老师正在获取业务数据...
跨境吴老师正在分析父商品流量与转化率异动...
跨境吴老师正在筛选30天趋势候选商品...
跨境吴老师正在判断30天双窗口趋势异动...
跨境吴老师正在生成负责人汇总表...
跨境吴老师正在生成负责人BI...
跨境吴老师正在生成异动明细BI...
跨境吴老师周数据分析已完成。
```

## 四、首次运行需要准备的信息

系统会根据实际情况引导补充配置。

| 信息 | 用途 | 是否需要每次输入 |
|---|---|---|
| 领星 MCP 开通与授权配置 | 获取业务数据 | 运行 Skill 前必须完成 |
| 老板管理邮箱 | 接收全部汇总结果 | 首次配置 |
| 负责人邮箱 | 向对应负责人发送本人明细 | 首次识别负责人或出现新负责人时 |
| 老板提供的发件邮箱 | 批量发送邮件 | 开启邮件发送前配置 |

重要提醒：

```text
不要在 Codex 对话窗口中输入邮箱密码、SMTP授权码或其他敏感凭据。
请按照系统提示，在安全配置流程中完成授权。
```

## 五、查看试运行结果

每次试运行完成后，系统会生成：

### 老板查看

```text
老板汇总包
```

老板汇总包默认是一个压缩包，包含负责人BI、汇总表、明细表和高优先级ASIN诊断入口。压缩包过大时，系统会自动生成轻量汇总包。

### 负责人查看

```text
该负责人的异动明细表
该负责人的异动明细BI
该负责人的高优先级ASIN诊断报告附件
```

负责人BI中的汇总关系：

```text
异动商品数 = 高优先级异动 + 待复核异动
```

其中：

| 类型 | 含义 |
|---|---|
| 高优先级异动 | 有历史数据，但历史规律无法解释当前变化，建议优先处理 |
| 待复核异动 | 无历史数据、样本不足、从0新增或负责人交接等情况，需要人工判断 |

系统会先判断单周期异动。未命中单周期阈值、但接近阈值的父商品，才会进入30天双窗口趋势判断：

```text
10% <= 流量变化绝对值 < 30%
或
20% <= 转化率变化绝对值 < 50%
```

趋势判断会对比最近30天的前7天和后7天；如果达到流量30%或转化率50%的趋势变化阈值，再进入历史判断、待复核判断和高优先级诊断流程。

异动明细表会标明：

```text
异动识别方式
趋势候选原因
趋势判断窗口
```

异动明细BI会展示：

```text
高优先级ASIN诊断报告入口
待复核异动统计
待复核异动明细
```

高优先级ASIN诊断报告不会把长文字直接塞进BI看板。BI中只显示ASIN入口，点击后打开对应诊断摘要或报告。

常见原因包括：

```text
从0新增
低样本
负责人变更
无历史数据
```

如果后续新增新的待复核原因，BI看板会按 `历史判断` 中的新原因文本动态展示在统计和明细中，不会隐藏。

## 六、重复手动试运行

在熟悉流程期间，可以随时输入：

```text
重新执行跨境吴老师周数据分析。
```

可以多次手动执行，不会自动开启邮件群发。

每次试运行结果通过校验后，系统会提示：

```text
1. 暂不开启，继续试运行
2. 配置邮箱并发送测试邮件
3. 开启每周自动发送
```

## 七、配置邮件发送

当需要配置发件邮箱时，输入：

```text
配置跨境吴老师周数据分析的邮件发送。
```

操作流程：

```text
输入老板提供的发件邮箱
→ 系统自动识别邮箱类型
→ 显示对应邮箱的操作指引
→ 按提示完成邮箱授权
→ 发送测试邮件
→ 测试成功后保存配置
```

例如：

| 发件邮箱 | 系统引导 |
|---|---|
| QQ邮箱 | 显示 QQ 邮箱授权码操作流程 |
| 163邮箱 | 显示网易邮箱授权码操作流程 |
| Outlook邮箱 | 显示 Microsoft 官方授权流程 |
| Gmail邮箱 | 显示 Google 官方授权流程 |
| 企业自定义邮箱 | 自动识别服务商；无法识别时提示协助配置 |

老板不需要手动填写：

```text
SMTP服务器
SMTP端口
SSL/TLS
STARTTLS
```

## 八、补充负责人邮箱

系统会自动识别当前数据中的负责人。

如果发现新负责人没有匹配邮箱，会显示：

```text
检测到新负责人：{负责人姓名}
请输入该负责人的接收邮箱：
```

输入有效邮箱后，系统保存映射关系。后续每周自动使用，无需重复输入。

如果负责人已经离职：

```text
不再向离职负责人发送邮件
只向本期负责人发送邮件
```

如果商品暂时没有负责人：

```text
对应结果发送给老板管理邮箱处理
```

## 九、开启每周自动发送

确认试运行结果和测试邮件都正常后，输入：

```text
开启跨境吴老师周数据分析每周自动发送邮件。
```

只有用户明确提出这条要求，系统才会创建自动任务。

自动运行规则：

```text
每周一 00:00：开始获取和处理数据
每周一 09:00：如果已经校验完成，开始发送邮件
09:00 尚未完成：实际完成并校验通过后立即发送
处理失败或校验失败：禁止发送不完整结果
```

第一次自动执行时间：

```text
用户明确开启自动发送后的第一个周一
```

## 十、邮件接收范围

### 老板管理邮箱

接收：

```text
老板汇总包
```

老板汇总包规则：

```text
默认发送1个完整压缩包
如果完整包超过发件邮箱可用附件阈值，自动改为轻量汇总包
不拆分为多个分卷压缩包
```

如果其他管理人员也需要查看，老板可以在自己的邮箱中设置转发。

### 负责人邮箱

仅接收：

```text
本人异动明细表
本人异动明细BI
本人高优先级ASIN的Word诊断报告
```

系统不会向负责人发送其他人的数据。

如果负责人的高优先级诊断报告较少，会逐个作为附件发送；如果报告较多，会打包成该负责人的诊断报告压缩包发送。

## 十一、日常使用短口令

首次安装、授权、邮箱配置和试运行期间，不需要记忆口令。请按照 Codex 的提示逐步完成配置。

配置完成后，日常使用只需要记住以下 7 条短口令。可以手动输入，也可以通过语音输入。

| 短口令 | 执行动作 | 是否需要二次确认 |
|---|---|---|
| `跑周报` | 手动执行本期异动分析，生成表格和BI | 否 |
| `看周报` | 打开本期负责人BI | 否 |
| `发周报` | 使用本期已经校验通过的结果发送正式邮件 | 是 |
| `开自动` | 开启每周自动处理与邮件发送 | 是 |
| `停自动` | 暂停每周自动处理与邮件发送 | 是 |
| `查状态` | 查看最近一次运行状态和邮件发送状态 | 否 |
| `更新模板` | 检查并同步基础版最新版本 | 是 |

涉及正式邮件、自动任务或模板更新时，系统会再次确认。

例如，输入：

```text
开自动
```

系统会提示：

```text
即将开启每周自动周报：
每周一 00:00 开始处理，
每周一 09:00 起发送校验通过的邮件。

请输入：确认开启
```

只有再次输入：

```text
确认开启
```

系统才会正式创建自动任务。

配置完成后，系统会显示一次：

```text
配置已完成。

日常可以直接输入：
- 跑周报
- 看周报
- 发周报
- 开自动
- 停自动
- 查状态
- 更新模板
```
