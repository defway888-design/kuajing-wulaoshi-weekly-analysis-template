# 高优先级诊断对接契约

## 1. 触发范围

只有 `最终状态 = 高优先级异动` 的父 ASIN进入深度诊断。`当期高优先异动`和`缓慢高优先异动`都必须进入。

按异动指标严格调度：

| 异动指标 | 必调诊断 |
|---|---|
| 流量异动 | 仅调用流量异动诊断 Skill |
| 转化率异动 | 仅调用转化率异动诊断 Skill |
| 流量+转化率异动 | 同时调用两个诊断 Skill，并生成一份父 ASIN综合报告 |

除`流量+转化率异动`外，禁止为了“更完整”而额外调用另一个诊断 Skill。

退货率只作为已确认缓慢下降的辅助风险核查：若 `高优先级类型=缓慢高优先异动` 且包含转化率下降，交转化率诊断；若包含流量下降，交流量诊断；组合异动仍是一条父 ASIN 记录。退货率翻倍或从0新增不独立触发异动、不改变已有分类或阈值，也不要求持续监控。仅转化率下降时不得为退货率而额外调用流量诊断或 SIF。

## 2. 上游输入

主 Skill 每次调用必须传入并在报告中保留：

```text
记录键
报告周期
站点
店铺
负责人
父ASIN
商品名
异动指标及方向
异动来源：单周期异动 / 30天双窗口趋势异动
当前比较窗口
基准比较窗口
当前流量值 / 基准流量值 / 流量变化率
当前转化率 / 基准转化率 / 转化率变化率
报告时区
报告时区来源
高优先级类型
```

在调度前按站点、店铺核实报告时区。先使用与本批数据同口径的报告元数据；元数据未明确提供时，提示`跨境吴老师需要确认<站点>/<店铺>所用 Amazon 报告时区及其来源。`，并记录用户确认来源。时区值必须能确定两个比较窗口内每一天的当地边界；跨越夏令时的窗口不得用未经验证的固定 UTC 偏移替代。不得从运行电脑时区、账号语言或站点国家推断。

每条诊断调用必须同时传递报告时区值、来源以及原始比较窗口，并将值和来源写入诊断索引。流量诊断只使用流量相关输入；转化率诊断还应接收同记录键、同窗口、同父 ASIN下可取得的全部子体`sessions_total`与`volume`汇总，用于贡献拆解。不得在诊断端自行改写报告窗口、回退到默认月份或猜测指标方向。

缓慢下降记录另传 `T-3`（30天趋势观察窗口末日）、对应站点/店铺、已确认的报告时区、父子 ASIN 集合及是否包含流量/转化率下降。退货率最近期固定为截至 `T-3`（含当日）的完整30个自然日，基准期为此前紧邻的完整30日，等长且不重叠；这两个窗口独立于趋势识别的前7天/后7天，也不替换诊断 Skill 的其他因素比较窗口。

主 Skill 在确认异动、报告时区和领星父商品有效子 ASIN 并集后，优先按两个日期窗各查询一次领星 `analytics_order_analysis_lists` 原始数据（`asinType=asin`、`dateType=0`，按退货时间；同店铺/站点，子 ASIN 可按工具能力分批，必须分页并校验精确返回行）。每期保存每个子 ASIN 的 `curReturnGoodsCount` 退货件数与 `curVolume` 同期销量件数及实际日期，不复用 `pre*` 字段、不平均行级比率，不使用转化率的订单量或卖家精灵/SIF 销量作分母。转化率诊断收到完整子体原始对象后自行筛出重点子 ASIN，流量诊断使用全部有效子 ASIN。只有原始件数、日期、店铺、子 ASIN、口径均匹配时，才向两侧传递同一内部证据对象；组合异动不重复查询。若主 Skill 尚未取数，先由被调度的一个诊断 Skill 按同一领星契约取数，再共享给另一侧，不得各自重复调用或跨 MCP 补数。

基准期退货率 > 0 时，仅最近期比率达到其2倍即命中，不设最低销量、最低退货件数或绝对百分点门槛；基准期销量 > 0、退货为0，最近期销量 > 0、退货 > 0 则标 `从0新增` 而非翻倍。任一期销量0、精确行缺失、件数缺失、分页或调用失败都记该子体 `数据不足`，不是0。即使退货件数未增、只是销量分母减少导致比率翻倍，仍命中风险，但必须注明可能由分母驱动。此比率是退货时间期间事件比，不是严格购买队列退货率或 Amazon 类目均值。

若经核实仍缺少报告时区，只对受影响的记录写入`诊断状态 = 诊断失败`、`核心诊断状态 = 阻断失败`、`可发送状态 = 禁止发送`和`阻断原因 = 报告时区缺失或无法确认`；报告时区与来源写`未获取`。不执行这些记录的期间诊断，不生成Word或正式行动方案，按记录键生成`待复核观察`且P0/P1留空。其他记录继续处理。流量+转化率异动仍为一条记录，可保留上游已核实的异动事实，但不得用未完成的一侧诊断生成正式综合结论。

## 3. 同源证据返回

每个诊断 Skill返回的运营可读报告、Word报告和结构化证据必须来自同一次诊断、同一个内部证据对象。主 Skill不得解析Word或自然语言报告后重新生成证据、原因或行动建议。

结构化证据的固定字段为：

```text
记录键
父ASIN
异动指标
异动方向
因素编码
因素名称
当前期证据
对比期证据
数据来源
证据状态
证据缺口
诊断结论
```

流量+转化率异动保留一个父 ASIN项目和一份综合Word报告；两个诊断的结构化证据按指标分别保留，并在同一`记录键`下合并给行动建议流程。

转化率侧只对既有重点子 ASIN（累计绝对贡献80%、最多5个）分别报告自身退货风险，并提示人工查看对应站点/子 ASIN 前台是否有高退货率标签；不自动查询或记录标签，不能把风险当成已证实的转化率下降原因。流量侧覆盖父商品全部有效子 ASIN；只有同一子 ASIN 的退货风险命中且 SIF 自然关键词排名也下降、实际时间段可比，才可报告候选关联。仅父级排名、子体无法映射或时间不可比时分别保留事实，不生成关联，不宣称 Amazon 因退货压低排名或退货高于类目均值。两侧输出来自同一原始件数，不合并成重复因素。

退货核查失败属于辅助证据缺口，仅影响该子体的退货因素，不导致整份诊断失败、禁止发送或整批暂停。退货风险不新建异动记录/BI卡片，不单独生成 P0/P1 行动或优化建议；现有其他可控制因素仍按原行动契约判断。

## 4. 状态映射

诊断 Skill返回状态映射到诊断索引：

| 诊断返回 | 诊断状态 | 核心诊断状态 | 诊断附件可发送 |
|---|---|---|---|
| 完整完成 | 已完成 | 完整完成 | 允许发送 |
| 可用但有证据缺口 | 部分完成 | 可用但有证据缺口 | 允许发送 |
| 诊断失败 | 诊断失败 | 阻断失败 | 禁止发送 |

单个 ASIN诊断失败时：

- 保留异动明细、负责人BI、异动明细BI和诊断索引行。
- 不生成虚构Word报告，不生成正式行动方案。
- 为该记录生成`待复核观察`，原因写`诊断失败，需人工复核`。
- 其他 ASIN、其他负责人和老板包继续处理。

`可发送状态`只表示该ASIN的诊断附件是否允许发送，不得作为整批邮件是否发送的唯一闸门。
