# 30天双窗口趋势异动规则

本文档固定跨境吴老师周数据分析Skill v1.5.0 的慢趋势异动补充识别规则。

## 业务目的

单周期异动规则只能识别当前周期已经达到阈值的突然变化。部分父商品可能连续多个周期缓慢下滑或上升，单期变化未达到阈值，但最近30天内部趋势已经明显变化。

30天双窗口趋势异动用于补充识别这类慢趋势变化。

## 执行顺序

```text
先执行单周期异动判断
→ 单周期已经命中异动：进入原有历史判断、待复核判断和高优先级诊断流程
→ 单周期未命中异动：继续判断是否进入趋势候选池
```

趋势判断不是全量商品第二次计算，只对候选池商品执行。

## 趋势候选池

只有符合以下任意条件的父ASIN，才进入30天双窗口趋势判断：

```text
10% <= 流量变化绝对值 < 30%
或
20% <= 转化率变化绝对值 < 50%
```

候选原因输出：

```text
仅流量进入候选池 -> 流量接近阈值
仅转化率进入候选池 -> 转化率接近阈值
流量和转化率同时进入候选池 -> 流量+转化率同时接近阈值
```

不符合候选池条件的父ASIN，不执行30天趋势计算，也不进入输出表。

## 数据调用方式

使用领星MCP的父ASIN维度区间汇总能力：

```text
tool = query_product_performance_asin_lists
summary_field = parent_asin
turn_on_summary = 1
date_type = purchase
```

本规则不要求MCP返回每日明细。按日期区间分别调用早期窗口、近期窗口和对应历史窗口即可。

## 当前趋势窗口

```text
观察窗口：最近30天，截止到T-3
早期窗口：最近30天中的前7天
近期窗口：最近30天中的后7天
中间16天：不参与计算，只作为缓冲区
```

输出字段：

```text
趋势判断窗口 = 最近30天前7天 vs 后7天
```

## 指标计算

流量：

```text
早期窗口日均流量 = early sessions_total / early days
近期窗口日均流量 = late sessions_total / late days
流量趋势变化率 = 近期窗口日均流量 / 早期窗口日均流量 - 1
```

转化率：

```text
早期窗口加权转化率 = early volume / early sessions_total
近期窗口加权转化率 = late volume / late sessions_total
转化率趋势变化率 = 近期窗口加权转化率 / 早期窗口加权转化率 - 1
```

## 趋势异动阈值

```text
流量趋势变化绝对值 >= 30%
转化率趋势变化绝对值 >= 50%
```

增加和减少都算异动。

异动指标输出：

```text
只命中流量趋势阈值 -> 流量异动
只命中转化率趋势阈值 -> 转化率异动
同时命中两个趋势阈值 -> 流量+转化率异动
```

## 历史判断

趋势异动必须用去年同期的相同窗口判断是否正常：

```text
去年对应30天观察窗口
去年早期窗口 = 去年对应30天中的前7天
去年近期窗口 = 去年对应30天中的后7天
```

历史容差沿用单周期规则：

```text
流量：当前趋势变化幅度与去年趋势变化幅度相差不超过10个百分点
转化率：当前趋势变化幅度与去年趋势变化幅度相差不超过15个百分点
```

判断结果：

```text
历史存在且能解释幅度 -> 认为正常，排除输出
历史存在且能解释幅度 -> 认为正常，排除输出
历史存在但不能解释幅度 -> 高优先级异动，且高优先级类型 = 缓慢高优先异动
无可比历史数据 -> 高优先级异动，且高优先级类型 = 缓慢高优先异动，历史判断记录无历史数据
```

历史判断必须看幅度接近，不只看方向一致。

缓慢异动属于高优先级异动，不属于待复核异动。所有命中的30天双窗口趋势异动都必须进入高优先级ASIN诊断报告流程。

## 特殊情况

低样本：

```text
早期窗口或近期窗口日均流量 <= 10，且趋势阈值被触发 -> 缓慢高优先异动
历史判断 = 缓慢高优先异动：样本不足，诊断中需重点关注样本波动
```

早期窗口为0：

```text
早期窗口值 = 0 且近期窗口值 > 0 -> 从0新增，缓慢高优先异动
早期窗口值 > 0 且近期窗口值 = 0 -> -100%，继续判断
早期窗口值 = 0 且近期窗口值 = 0 -> 不输出
```

负责人变更：

```text
如果当前周期与上期负责人不同，且趋势异动被触发 -> 缓慢高优先异动
历史判断 = 缓慢高优先异动：负责人变更：上期{previous_owner} -> 本期{current_owner}，诊断中需确认交接或运营动作影响
```

## 输出字段

趋势异动进入异动明细表时必须包含：

```text
异动识别方式 = 30天双窗口趋势异动
趋势候选原因 = 流量接近阈值 / 转化率接近阈值 / 流量+转化率同时接近阈值
趋势判断窗口 = 最近30天前7天 vs 后7天
最终状态 = 高优先级异动
高优先级类型 = 缓慢高优先异动
```

单周期异动进入异动明细表时：

```text
异动识别方式 = 单周期异动
趋势候选原因 = 空
趋势判断窗口 = 空
```
